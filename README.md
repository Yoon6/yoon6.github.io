# Max Yoon Portfolio

React and TypeScript portfolio site for GitHub Pages.

## Run Locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The production output is written to `dist/`.

## Content

- Edit profile, links, focus areas, and projects in `src/data/profile.ts`.
- Edit the Typst resume source in `src/data/resume-cur.typ`.
- The resume page renders Typst in the browser through Typst.ts.
